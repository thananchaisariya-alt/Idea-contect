## เปิดเว็บบล็อกบน GitHub Pages

1. รวม (merge) งานนี้เข้า branch หลัก
2. ไปที่ **Settings → Pages** ของ repo
3. ที่ **Source** เลือก *Deploy from a branch* แล้วเลือก branch หลัก โฟลเดอร์ `/ (root)` กด Save
4. รอสักครู่ เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/Idea-contect/`

ถ้าเปลี่ยนชื่อ repo หรือใช้โดเมนของตัวเอง ให้แก้ค่า `baseurl` ใน `_config.yml`

## เพิ่มบทความใหม่

สร้างไฟล์ใน `_posts/` ตั้งชื่อ `ปี-เดือน-วัน-ชื่อภาษาอังกฤษ.md` เช่น `2026-11-15-what-is-dianping.md` แล้วขึ้นต้นไฟล์ด้วย

```yaml
---
layout: post
lang: th            # th = แสดงในหน้าไทย, zh = แสดงในหน้า 中文
title: "ชื่อบทความ"
category_label: "แพลตฟอร์มจีน"
excerpt_text: "คำโปรยหนึ่งถึงสองประโยค"
---
```

จากนั้นเขียนเนื้อหาเป็น Markdown ต่อได้เลย

## ดูเว็บในเครื่อง (ไม่จำเป็น)

```bash
gem install jekyll -v "~> 3.10"
gem install kramdown-parser-gfm webrick
jekyll serve
```

## ก่อนเผยแพร่จริง

- เปลี่ยนชื่อช่องและคำโปรยใน `_config.yml` และใส่ช่องทางติดต่อใน `about.md`
- บทความภาษาจีนควรให้เจ้าของภาษาอ่านตรวจหนึ่งรอบ
- ตรวจข้อมูลที่เปลี่ยนได้ เช่น กฎเข้าเมืองและวิธีชำระเงิน ให้ตรงกับประกาศล่าสุด
- ยืนยันข้อมูลที่พักในหัวข้อ 1 ของแผน WABI SABI แล้วเติมส่วนที่อยู่ใน【】ของร่างใน `_drafts/` ก่อนย้ายไป `_posts/`
