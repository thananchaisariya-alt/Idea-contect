# คู่มือการตลาดจีน (ฉบับเริ่มต้น)

เอกสารภายใน ไม่ถูกเผยแพร่บนเว็บบล็อก

## 1. กลุ่มเป้าหมายที่ทำก่อน

| | A. นักท่องเที่ยวจีนในไทย | B. คนไทยที่สนใจจีน |
|---|---|---|
| ภาษา | จีนตัวย่อ | ไทย |
| เขาต้องการอะไร | ข้อมูลที่ใช้ได้จริง: ไปไหน กินอะไร จ่ายอย่างไร ระวังอะไร | เข้าใจตลาดจีน เทรนด์ แพลตฟอร์ม วิธีขายคนจีน |
| อยู่ที่ไหน | Xiaohongshu, Douyin, Dianping, WeChat | Facebook, TikTok, YouTube, Google |
| เราได้อะไร | ลูกค้าเดินเข้าร้าน / จองบริการ | ผู้ติดตาม ความน่าเชื่อถือ งานที่ปรึกษาหรือสปอนเซอร์ |

กลุ่ม "คนจีนในจีน" (ขายข้ามแดน) เก็บไว้เฟสถัดไป เพราะต้องมีเรื่องโลจิสติกส์ ภาษี และร้านบนแพลตฟอร์มอีคอมเมิร์ซจีน

กลุ่ม B ใช้ช่องทางไทยตามปกติ: บล็อกนี้ (ให้ Google ค้นเจอ) + Facebook Page + TikTok

## 3. เส้นทางของนักท่องเที่ยวจีน

1. **ก่อนเดินทาง** ค้น Xiaohongshu และ Douyin ด้วยคำอย่าง `曼谷攻略` `泰国美食` แล้วเซฟโน้ตไว้ → เราต้องมีโน้ตที่ค้นเจอ
2. **ระหว่างอยู่ไทย** เปิดลิสต์ที่เซฟ ดูคะแนนใน Dianping ดูแผนที่ → ข้อมูลร้านต้องถูก หาง่าย
3. **หน้าร้าน** อ่านเมนู สั่ง จ่าย → เมนูจีน และรับ Alipay / WeChat Pay
4. **หลังใช้บริการ** โพสต์รีวิว → ทำให้ถ่ายรูปง่าย มีชื่อร้านภาษาจีนให้แท็ก

ลงทุนจากข้อ 3 ย้อนขึ้นไป ถ้าหน้าร้านยังไม่พร้อม การดันคนมาก็ได้รีวิวแย่

## 4. แผน 90 วัน

**เดือนที่ 1 — วางฐาน**
- กรอกข้อมูลธุรกิจในหัวข้อ 7 ให้ครบ
- ตั้งชื่อแบรนด์ภาษาจีน ให้เจ้าของภาษาตรวจความหมายและเสียงพ้อง
- เปิดบัญชี Xiaohongshu ตรวจหน้า Dianping และหมุดแผนที่
- ทำเมนู/โบรชัวร์ภาษาจีนตัวย่อ และตรวจช่องทางรับเงิน
- เผยแพร่บล็อกไทย 4 บทความ เปิดเพจ

**เดือนที่ 2 — สร้างรีวิวสะสม**
- โพสต์ Xiaohongshu สัปดาห์ละ 3 โน้ต (ดู `03-content-plan.md`)
- เชิญ KOC 10–15 คน เน้นคนจีนที่อยู่ในไทย (ดู `02-kol-guide.md`)
- บล็อกไทยสัปดาห์ละ 2 บทความ ตัดเป็นคลิปสั้นลง TikTok

**เดือนที่ 3 — ขยายสิ่งที่ได้ผล**
- ดูว่าโน้ตและ KOC คนไหนพาคนมาจริง ทำซ้ำแนวนั้น
- ทดลอง KOL ระดับกลาง 1–2 คน
- พิจารณาโฆษณาบนแพลตฟอร์ม เฉพาะกับโน้ตที่ไปได้ดีเองอยู่แล้ว

## 5. ตัวชี้วัด

| ระดับ | วัดอะไร | วิธีเก็บ |
|---|---|---|
| ถูกค้นเจอ | จำนวนโน้ตที่พูดถึงเรา อันดับเมื่อค้นคำหลัก | ค้นเองทุกสัปดาห์ จดลงตาราง |
| สนใจ | ยอดเซฟ (收藏) และคอมเมนต์ถามทาง ราคา | ยอดเซฟสำคัญกว่ายอดไลก์ เพราะแปลว่าตั้งใจจะมา |
| มาจริง | จำนวนลูกค้าจีนต่อสัปดาห์ | ถามหน้าร้านว่า "รู้จักจากไหน" หรือใช้โค้ดส่วนลดแยกตามคนรีวิว |
| กลุ่ม B | ผู้เข้าชมบล็อก ผู้ติดตามเพจ ข้อความติดต่องาน | สถิติของแต่ละแพลตฟอร์ม |

## 6. ข้อควรระวัง

- **ตัวย่อเท่านั้น** สำหรับจีนแผ่นดินใหญ่ และให้เจ้าของภาษาตรวจทุกชิ้นก่อนเผยแพร่
- **คำต้องห้ามในโฆษณา** กฎหมายโฆษณาของจีนห้ามคำขั้นสุด เช่น 最好 (ดีที่สุด) 第一 (อันดับหนึ่ง) 国家级 (ระดับชาติ) แพลตฟอร์มจะลดการมองเห็นหรือลบโพสต์
- **ห้ามพาออกนอกแพลตฟอร์ม** Xiaohongshu เข้มกับการใส่ลิงก์ภายนอก QR หรือ ID แอปอื่นในโน้ต
- **งานจ้างต้องเปิดเผย** ทั้งกฎของแพลตฟอร์มและกฎหมายกำหนดให้ระบุว่าเป็นโฆษณา ใช้ช่องทางร่วมงานทางการของแพลตฟอร์มจะปลอดภัยกว่า
- **หัวข้ออ่อนไหว** เลี่ยงการเมือง แผนที่และเขตแดน ศาสนาในเชิงล้อเลียน และการเปรียบเทียบเชิงดูถูก
- **สินค้าที่มีกฎเฉพาะ** อาหารเสริม ยา เครื่องสำอาง ความงามทางการแพทย์ การเงิน มีข้อจำกัดการโฆษณาเข้มมาก ต้องตรวจกฎก่อนทำ
- **กฎเปลี่ยนบ่อย** เงื่อนไขเปิดบัญชีธุรกิจสำหรับบริษัทต่างชาติและกฎโฆษณา ให้ตรวจจากหน้าทางการของแพลตฟอร์มทุกครั้ง
